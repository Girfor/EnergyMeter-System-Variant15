## Запуск

Требуются Windows, Visual Studio с поддержкой .NET 8 или .NET 8 SDK. Для проекта, работающего через HTTPS, может потребоваться доверить локальный сертификат разработчика.

1. Открыть файл `.sln` выбранного модуля из папки `demos/` или объединенное решение `src/EnergyMeterPortfolio/EnergyMeterPortfolio.sln`.
2. В Visual Studio назначить запускаемым проектом приложение (не библиотеку классов).
3. Запустить проект клавишей F5 и изучить результат встроенных демонстрационных проверок.
4. Подробные инструкции и ограничения находятся в README конкретных модулей.

Для `demos/backup-sat/` после запуска следует сохранить созданный протокол SAT и заполнить поля фактических испытаний отдельно.

## Подтвержденные результаты учебных демонстраций

- **EnergyMeter API:** 18 из 18 встроенных проверок — PASS.
- **Security Demo:** 10 из 10 встроенных проверок — PASS.
- **BackupSAT Demo:** восемь проверок резервирования и восстановления — PASS после устранения ошибки формирования SHA-256.
- **Offline Buffer:** локальный прогон с пятью показаниями, повторами при HTTP 503, сохранением данных и защитой от повторного EventId — PASS.
- **Auto Updater:** локальные проверки SemVer, SHA-256, staging и поврежденного пакета — PASS.

Важно: это результаты **учебных локальных запусков**, а не акт промышленной приемки. SAT-01–SAT-06 требуют отдельных испытаний в целевой инфраструктуре; для SAT-07 желательно повторное восстановление на независимом узле с протоколом и подписями.

## Безопасность

Репозиторий содержит учебные, а не эксплуатационные примеры. Не используйте демонстрационные логины/пароли как реальные учетные данные. Секреты API и пароли для своего развертывания следует передавать через переменные окружения или менеджер секретов; не размещайте `.env`, реальные базы, ключи и файлы закрытых сертификатов в Git.
